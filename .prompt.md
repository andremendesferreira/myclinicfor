# 🏥 Contexto do Projeto MyClinicSOL

## 📋 Informações Básicas
- **Nome:** MyClinicSOL (Minha Clínica de Soluções)  
- **Repositório:** https://github.com/andremendesferreira/myclinicfor

- **Localização:** Fortaleza, Ceará, Brasil
- **Descrição:** Plataforma de gerenciamento para clínicas focada em otimizar agendamentos e gestão de profissionais de saúde

- **Backend:** Next.js API Routes
- **Database:** PostgreSQL (Neon)
- **ORM:** Prisma 6.14.0 (output: `../src/generated/prisma`)
- **Auth:** NextAuth.js 5.0.0-beta.28
- **Payments:** Stripe
- **State Management:** TanStack Query
- **Forms:** React Hook Form + Zod

## 🎯 Funcionalidades & Regras de Negócio

### Sistema de Ranking (vw_professional_ranked)
**Critérios de Ordenação:**
1. **Plano** (prioridade): TOP(0) → PREMIUM(1) → PROFESSIONAL(2) → BASIC(3) → FREE(4)
2. **Status da assinatura** (DESC)
3. **Data de atualização** (ASC)

**Observação sobre TOP:**
- 🎯 TOP é usado apenas para priorizar clínicas na busca
- 💼 Não é um plano comercial com funcionalidades próprias
- ⭐ Clínicas com TOP aparecem primeiro nos resultados
- 🔧 Herda todas as funcionalidades do plano PREMIUM

**Filtros para aparecer no ranking:**
- ✅ `status = true` (usuário ativo)
- ✅ `times` não vazio (possui horários)  
- ✅ `address` não nulo (possui endereço)
- ✅ `activities` não vazio (possui especialidades)

### Sistema de Agendamentos
- **Público:** Usuários podem agendar via `/clinic/[id]`
- **Privado:** Profissionais gerenciam via dashboard
- **Validações:** CPF, horários disponíveis, serviços ativos

### Sistema de Assinaturas (Stripe)

**Planos Comerciais:**

| Plano | Preço | Promo | Serviços Ativos | Cadastro Max | Layout |
|-------|-------|-------|-----------------|--------------|--------|
| **FREE** | R$ 4,99 | **R$ 0,00** | 2 | 5 | 0 |
| **BASIC** | R$ 29,99 | **R$ 24,99** | 5 | 10 | 1 |
| **PROFESSIONAL** | R$ 59,99 | **R$ 49,99** | 25 | 30 | 2 |
| **PREMIUM** | R$ 97,99 | **R$ 79,99** | 50 | 55 | 3 |

**Funcionalidades por Plano:**

```typescript
// FREE - Funcionalidades básicas
- ✅ Agendamento de consultas
- ✅ Página de agendamento
- ✅ WhatsApp informativo
- ✅ Atualização para planos pagos

// BASIC - Pequenas clínicas
- ✅ Todas do FREE
- ✅ Contato com suporte

// PROFESSIONAL - Médio porte  
- ✅ Todas do BASIC
- ✅ Registro de consultas
- ✅ Personalização de perfil

// PREMIUM - Grande porte
- ✅ Todas do PROFESSIONAL  
- ✅ Ferramentas de IA
- ✅ Transcrição de voz em texto
```

**Sistema TOP (Apenas Ranking):**
- 🎯 **TOP:** Usado exclusivamente para priorizar clínicas na busca da página inicial
- 🚫 **Não é plano comercial:** Não possui preço, recursos ou funcionalidades específicas
- ⭐ **Função:** Permite que clínicas paguem para aparecer no topo dos resultados de busca

## 🚨 Tratamento de Erros & Validação

### Padrões de Error Handling
```typescript
// Server Actions com try/catch
export async function createPatient(data: CreatePatientData) {
  try {
    const validatedData = createPatientSchema.parse(data)
    const result = await prisma.patient.create({
      data: validatedData
    })
    return { success: true, data: result }
  } catch (error) {
    console.error('Error creating patient:', error)
    return { success: false, error: 'Erro ao criar paciente' }
  }
}

// Validação com Zod
const createPatientSchema = z.object({
  nome: z.string().min(2, 'Nome deve ter pelo menos 2 caracteres'),
  cpf: z.string().regex(/^\d{11}$/, 'CPF deve ter 11 dígitos'),
  email: z.string().email('Email inválido'),
  telefone: z.string().min(10, 'Telefone inválido')
})
```

  const sig = headers().get('stripe-signature')!
  const event = stripe.webhooks.constructEvent(body, sig, webhookSecret)
  
  switch (event.type) {
    case 'customer.subscription.updated':
      await updateSubscription(event.data.object)
      break
    case 'customer.subscription.deleted':
      await cancelSubscription(event.data.object)

  }
